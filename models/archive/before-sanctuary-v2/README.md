# Models before the Sanctuary correction

These frozen artifacts and their accompanying qualification records preserve the
previous ladder. Its benchmark allowed importing entire formations into Sanctuary,
including sheltering several during creation. Those results do not qualify the
models under the corrected rules.

Each `*.qualification.json` records the original runtime weights, report path,
and model hash. The original `models/<level>.json` path in a historical report
now refers to the same level in this archive. Runtime source hashes in those
reports identify the historical implementation; commit `c2b6df8` contains the
complete original ladder. Current qualifications live in `models/registry.json`.
